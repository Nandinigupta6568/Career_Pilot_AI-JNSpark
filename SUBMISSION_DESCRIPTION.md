# Devpost submission draft

## Project name
CareerPilot AI — From Career Goal to Action Plan

## Problem
Students and early-career applicants often know the role they want but do not know which skills to prioritize, how to structure their preparation time, or which practical projects can demonstrate their ability.

## Target users
University students, recent graduates, and early-career applicants preparing for internships or entry-level roles.

## What the agent does
CareerPilot AI uses ASI:One as its reasoning layer and exposes allow-listed tools for skill-gap analysis, week-by-week study planning, curated learning resources, and live public GitHub repository search. It returns a practical plan and links that a user can act on.

## How it fits the Fetch-A-Thon challenge
The intended workflow starts with a natural-language career goal, reasons about the user's needs, calls relevant tools, and returns a concrete plan. The agent uses the uAgents framework and the standard chat protocol intended for ASI:One-compatible agents.
